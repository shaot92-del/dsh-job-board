## 走查方法（可复制）

1. 重启 DSH（当前运行 2.6.29，磁盘 2.7.1）。
2. 打开面板 → DevTools → Console 勾 **Preserve log**（Network 也勾）。
3. 按表逐格操作；每条截图存 `docs/audit-2.7.1/shots/`。
4. **数据翻转**：先把板子数据清到空（或断网使 `summary` 为空）→ 打开派工框 → 恢复数据 → 停在弹窗上等 `tick` 刷新，①看弹窗是否仍在、②模型区是否从置灰项切到分组清单、③控制台是否出现 `#130` 或 `slot entry crashed`。
5. 任一条出现 React error / 整槽白屏 → 记 `FAIL` 并阻断发布。

## 判定

- 全部 `PASS` 且含至少一条翻转形态 → 本节 `PASS`。
- 出现白屏 / React error 未解释 → `FAIL`，阻断发布。
- 无法执行（例如无法重启 DSH）→ `BLOCKED`，写明需要谁补做。
